# Aether | Premium Blog Platform

Aether is a production-ready, full-stack blogging platform built with Next.js, MongoDB, and AWS S3.

## Features
- **Modern UI**: Rich, dynamic experience with stunning animations.
- **Rich Editor**: Flexible content creation tool.
- **Secure**: Authentication with Auth0.
- **Media Management**: Robust image and video uploads to AWS S3.
- **Database**: Performant MongoDB integration.

## Getting Started
To run locally:
1. Clone the repository.
2. Install dependencies: `npm install`.
3. Set up environment variables in `.env`.
4. Run the development server: `npm run dev`.

Open [http://localhost:3000](http://localhost:3000) to view the application.
